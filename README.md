# PATTI CROP

**動画の上下左右クロップ + Windows/iPhoneで再生できる形式への変換ツール（無料）**

画面録画からブラウザのブックマークバーやタスクバーを切り落としたり、
プロ用カメラの動画（H.264 4:2:2 10-bit など）を
Windows・iPhoneで確実に再生できるMP4に変換できます。

by STUDIO PATTI

---

## インストール（初回だけ）

1. このページの緑の **「Code」→「Download ZIP」** でダウンロード
2. zipを右クリック →「すべて展開」で好きな場所に展開（例: ドキュメント）
3. 展開したフォルダの **`setup.bat`** をダブルクリック
   - Python・ffmpegのチェックと、デスクトップショートカットの作成を自動でやります
   - ffmpegが無い場合は自動インストールを試みます（数分かかります）
4. 完了すると自動でアプリが起動します

> **Pythonが入っていない場合**: https://www.python.org/downloads/ からインストールしてください。
> インストール画面で **「Add python.exe to PATH」に必ずチェック** を入れること！

## 使い方

デスクトップの **PATTI CROP** アイコンをダブルクリック → ブラウザでアプリが開きます。

1. **① 動画ファイルを選ぶ** — ファイルを選択（**複数選択OK**。パス貼り付けでも追加可）
2. **② クロップ範囲を調整** — プレビュー上でドラッグして移動、角をつまんでリサイズ。
   アスペクト比プリセット（16:9 / 9:16 / 1:1 / 4:3 / フリー）付き。
   クロップ不要なら「クロップなし」のまま進めてOK。
   ファイルリストをクリックすると1本ずつ別々のクロップを設定でき、
   「⧉ このクロップを全ファイルに適用」でまとめて同じ設定にもできる
3. **③ まとめて変換スタート** — リストの上から順に自動で全部変換。
   完了したら「📁 フォルダを開く」で出力先へ

- 出力は H.264 + AAC の MP4（Windows / iPhone / Android すべて再生OK）
- 出力先は「元ファイルと同じフォルダ」か、好きなフォルダを指定可能
- 元ファイルは変更されません（別名で新規保存）
- 終了はアプリ画面右上の「⏻ アプリを終了」ボタン

## 一度に処理できる本数・容量

**上限はありません。** ファイルは「上から順に1本ずつ」処理されるため、
何本追加してもPCのメモリを圧迫しません（合計何GBあってもOK）。
気にするのは **出力先の空き容量** と **変換にかかる時間** だけ。

※CPU変換だと4K動画は1本あたり時間がかかります。
NVIDIA GPU + ドライバ570以降なら高速エンコードで一気に速くなります。

## アップデート

フォルダ内の **`update.bat`** をダブルクリックするだけ。
最新版のダウンロード → 適用 → 再起動まで全自動です。設定は引き継がれます。
（zipを手動でダウンロードする必要はありません。うまくいかない時だけ、
配布ページのzipをダウンロードフォルダに入れてから update.bat を実行）

## 動作環境

- Windows 10 / 11
- Python 3.x（無料・上記参照）
- ffmpeg（無料・setup.batが自動インストール）
- NVIDIA GPU搭載PCならGPU高速エンコード対応（ドライバ570以降。無くてもCPUで動きます）

## ファイル構成（開発者向け）

| ファイル | 役割 |
|---|---|
| `server.py` | ローカルHTTPサーバー本体（Python標準ライブラリのみ・外部送信なし） |
| `index.html` | UI |
| `PattiCrop.vbs` | 無音起動ランチャー（ショートカットの実体） |
| `setup.bat` / `setup.ps1` | 初回セットアップ |
| `update.bat` / `update.ps1` | ワンクリックアップデーター |
| `create_shortcut.bat` | ショートカット再作成 |
| `PATTI_CROP.bat` | コンソール表示付き起動（デバッグ用） |
| `repo_url.txt` | アップデートのダウンロード元URL |
| `config.json` / `server.pid` | 実行時に自動生成（リポジトリには含めない） |

※ 完全ローカル動作。動画がネットにアップロードされることはありません。

### 更新版の出し方（メンテナ用メモ）

`server.py` の `APP_VERSION` を上げて main ブランチにpushするだけ。
利用者の update.bat が `repo_url.txt` のURL（mainブランチのzip）を取得して適用する。
.batはASCIIのみ（cmdはUTF-8日本語を化かす）、日本語メッセージはBOM付きUTF-8の.ps1に書くこと。
