🚀 はじめかた（3ステップ）

  1. 上の 「⬇ 無料ダウンロード」 を押す → patti_crop.zip が保存されます
  2. zipを右クリック →「すべて展開」で好きな場所に展開
  3. 出てきたフォルダの setup.bat をダブルクリック → デスクトップにアイコンができて起動します
初回だけ、変換エンジン（約170MB）を自動ダウンロードします。
アップデートはアプリが自動でお知らせ → ボタン1つで完了。

🖥 動作条件

  • Windows 10 / 11（Macやスマホでは動きません）
  • 初回セットアップ時のみインターネット接続
  • 追加インストール不要。NVIDIA GPUがあれば高速変換（無くてもOK）

📖 詳しく知りたい人へ

できること

ドラッグでクロップ範囲を調整（16:9 / 9:16 / 1:1 / 4:3 / フリー）。プロ用カメラの動画（H.264 4:2:2 10-bitなど）も再生できるMP4に変換。複数ファイルの一括処理OK・本数上限なし。

プライバシーは大丈夫？

動画はPCの中だけで処理され、外部に送信されません。AIも未使用。通信は初回の変換エンジン取得と更新確認のみ。元の動画も消えません（別名で新しく保存）。

アップデートはどうやる？

新しいバージョンが出るとアプリ起動時にお知らせが出ます。「今すぐ更新」を押すだけで適用・再起動まで全自動。設定（出力先など）も変換エンジンも引き継がれるので、待ち時間はほぼありません。

zipを取り直したい場合は、上のボタンから最新版をダウンロードして展開し setup.bat を実行すればOK。デスクトップのアイコンは自動で最新版に付け替わるので、そのままダブルクリックで使えます。（フォルダ内の update.bat でも手動更新できます）

もっとラクに読み込みたい

動画を右クリック →「送る」→ PATTI CROP でそのまま読み込めます。アプリ内の「📂 動画を選ぶ」からデスクトップ／ダウンロード／ビデオ／ドキュメントを辿って複数選択することもできます。

アイコンが消えた・作り直したい

アプリを起動すれば自動で作り直されます。すぐ作りたいときはフォルダ内の create_shortcut.bat をダブルクリックしてください。

商用利用できる？

できます。権利を持たない動画の変換・再配布はNG。
