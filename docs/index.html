🎬 こんなことができる

✂️

ドラッグでクロップ

スマホみたいにマウスでクロップ範囲を調整。16:9 / 9:16 / 1:1 / 4:3 / フリーのプリセット付き。画面録画からタスクバーを切り落とすのも簡単。

🔄

再生できる形式に変換

プロ用カメラの動画（H.264 4:2:2 10-bitなど）を、Windows・iPhone・スマホで確実に再生できるMP4に。「サポートされていないエンコード設定」エラーとサヨナラ。

📚

まとめて一括処理

何本でもドンと追加OK。1本ずつ別々のクロップも、全ファイルに同じクロップの一括適用も自由。クロップなしの「変換だけ」もできます。

🔒

完全ローカル動作

動画はネットに一切送信されません。AIも使っていないので学習もされません。全部あなたのPCの中で完結します。

🚀 はじめかた（3ステップ）

  1. 上の 「⬇ 無料ダウンロード」 を押す
    （またはGitHubの緑の 「Code」→「Download ZIP」）→ zipファイルが保存されます
  2. 保存したzipを右クリック →「すべて展開」
    好きな場所（例：ドキュメント）に展開
  3. 出てきたフォルダの setup.bat をダブルクリック
    Python・ffmpegのチェック → ffmpeg自動インストール → デスクトップにアイコン作成 → 起動まで全部自動で進みます
⚠ Pythonが入っていない場合：python.org からインストールしてください。 インストール画面の 「Add python.exe to PATH」に必ずチェック を入れるのがコツです（ここだけ注意！）。

🔃 アップデート

フォルダ内の update.bat をダブルクリックするだけ。
最新版のダウンロード → 適用 → 再起動まで全自動。設定はそのまま引き継がれます。

❓ よくある質問

動画がAIに学習されたりしない？

されません。そもそもAIは使っていません。動画はあなたのPCの中だけで処理され、外部に送信されることはありません。

動画がどこかのサーバーに保存されない？

されません。完全ローカル動作で、出力ファイルもあなたのPC内だけ。元のファイルも変更されません。

ネット通信は本当にないの？

変換処理は通信ゼロです。通信するのは「初回 setup.bat のffmpeg自動インストール」と「update.bat の更新チェック」のときだけ。

オフラインで使える？

使えます。セットアップさえ終われば、機内モードでも動きます。

一度に何ファイルまで？合計何GBまで？

上限はありません。ファイルは上から順に1本ずつ処理されるので、何本・何GBあってもPCのメモリを圧迫しません。気にするのは「出力先の空き容量」と「変換にかかる時間」だけです（CPU変換だと4Kは1本ずつ時間がかかります）。

元の動画は消えたり変わったりする？

消えません・変わりません。「元のファイル名＿crop.mp4」などの別名で、新しく保存されます。

Macで使える？

現在はWindows専用（Windows 10 / 11）です。

商用利用できる？

できます。ただし、あなたが権利を持たない動画の変換・再配布はしないでください。

なぜ無料なの？怪しくない？

「クリエイターがちょっと助かるツールを無料で公開する」という STUDIO PATTI の活動の一環です（このページの広告枠などで運営しています）。全ソースコードをGitHubで公開しているので、中身は誰でも確認できます。

アップデートはどうやる？

フォルダ内の update.bat をダブルクリックするだけです。GitHubから最新版を自動ダウンロードして適用・再起動まで全自動、設定も引き継がれます。zipを手動でダウンロードする必要はありません。
